# Norway 2026 · 3D Travel Story

An interactive travel website for an 11-day journey through Norway, from Stavanger and Lofoten to Tromsø and Oslo.

## Features

- Scroll-driven MapLibre 3D globe
- Detailed GLB car, aircraft, and cruise ship models
- Real road, flight, and coastal voyage routes
- Hybrid high-resolution satellite and vector map
- Daily itinerary, attractions, food, and booking links
- Responsive mobile presentation and reduced-motion support

## Development

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run build
npm run lint
```

## Deployment

The site is deployed automatically to GitHub Pages whenever `main` is updated.
